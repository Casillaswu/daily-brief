    预警规则
    纳入条件
    近7日消耗 ≥ $3,000 且一级首充 ≥ 30 人，且前7日有一级首充金额（小渠道百分比噪音太大，不进预警）
    红灯
    一级首充ROAS 近7日比前7日跌 ≥ 25%；或跌 15–25% 且近3日比前3日也跌 ≥ 15%（两个窗口同向）
    黄灯
    近7日跌 15–25%；或跌 ≥ 25% 但近3日比前3日回升 ≥ 10% 且近3日首充 ≥ 20 人（标「回升中」）
    大盘同步
    全站（两总代合计）近7日平均首充客单比前7日跌 > 10% 时，主因是「首充客单」的红灯降为黄灯并注明「大盘同步」——问题在活动/档位/营运端，不在投手
    顶部红条
    任一总代近7日 总ROAS 升 > 5% 且一级首充ROAS 跌 > 3% 时出现：总ROAS 是老客复充撑出来的，不代表新买进来的量
    主因
    一级首充ROAS =（注册 ÷ 消耗）×（首充 ÷ 注册）×（首充金额 ÷ 首充），拆成「注册成本 / 注册转首充 / 首充客单」三段，跌最多的那段就是主因；第二段的跌幅达第一段的 80% 以上时标「混合」
    排序与影响金额
    同灯号内按影响金额排序：近7日消耗 ×（前7日一级首充ROAS − 近7日一级首充ROAS），即按原本效率估算这段时间少收的一级首充金额
    2日 / 3日 / 7日
    最近 N 个数据日 vs 再往前 N 个数据日；2日只当早期信号，不触发灯号
    为什么不用总ROAS
    总ROAS 含渠道老用户复充，会随时间自然变好看；两者方向相反时，总结会特别标出「老客撑盘」
    包型
    取渠道名称第一段（原生包 / 轻量包 / H5 / PWA）
    媒体
    按渠道名称关键字判断：FB/Facebook → Facebook；GG/GGS/谷歌/SEM → Google；TT/TikTok → TikTok；Kwai → Kwai；Mobflyer、Nativex、Liftoff、Moloco、Unity、PropellerAds、Moboost、iClick 等 → 程序化/网盟；其余 → 未标注（A8 多数渠道名称只有代理代号，会落在这里）
