▲Executive Briefing · 主管简报

这一周看点

这周三件事： SONA 于 7/27 召开，是未来一周最大政策变数； PAGCOR 同时收紧洗钱规范、调降实体赌场费率、解构自营赌场； DigiPlus 继续闷声集中，VIP Club 往高端加码。

1. SONA 于 7/27 召开。这是未来一周最大的政策变数。
SONA 是宪法定的 7 月第四个周一 = 7/27，是 Marcos（现任菲律宾总统 Ferdinand Marcos Jr.）第五次施政报告、约下午 4 点开讲。多位议员这几天连番喊话要总统当场处理线上博彩（Valeriano 全国禁、Bong Go SB 686、Pangilinan、Zubiri SB 142）。去年（2025）一堆人喊，Marcos 全程没提，被读成不想被逼着一刀切。这次会不会破例，几小时后见分晓。详 §04 卡 1。(出处：GMA · SONA 2026 · BusinessWorld 7/16)

2. PAGCOR 同时在做三件方向不一样的事：收紧洗钱规范、调降实体赌场费率、解构自营赌场。
7/13 发的 AML 顾问令 7/21 被产业媒体放大（六家以上同步报），把全菲赌场业定调为洗钱「高风险」，要全业重做风险评估、CDD、可疑交易通报。同一周，调降实体赌场费率（线上整合度假村降到 25%、实体降到 30%）跟解构自营赌场（把监管跟自营赌场拆开、卖掉 Casino Filipino，估值 ₱300-500 亿）也都在推、8 月要送总统府。一手压合规、一手降成本、一手改结构，指向同一件事：这个市场在重整、不是简单的涨或跌。详 §04 卡 2、卡 3。(出处：IAG/ASGAM 7/21 · AGB 7/19)

3. DigiPlus 继续闷声集中，别家还是没动作。
回购在执行、均价约 ₱39，₱6 亿额度还剩 ₱5.36 亿；7/19 又把 BingoPlus VIP Club 重新包装（「Unlock the Code of the New Nobility」化妆舞会，Manila Marriott），往高消费客群走。嘉年华 7/23 收了，其余 8 家窗口内 0 新档。世界杯完到 8 月旺季前的体育空窗还开着。详 §04 卡 4。(出处：InsiderPH · 回购均价 ₱39 · VIP Club 改版)

合规SONA 今天讲，结果没出来前别放大投放；AML 令让支付 / KYC / junket 文案审查权重再往上调，业配 brief 支付透明度这条抓更紧。
市场降费率是实质纾困，但它跟 AML 收紧、盘子缩同时发生——别把降费率单独读成利多。到底跌多少，月底第二季数字才知道。
体育档世界杯完到 8 月旺季前还是空的，用低成本内容先占，比跟 BingoPlus 拼奖金 / 拼 VIP 排场划算。

§02Strategic Read · 5Q

战略解读 · 五问（中性陈述）

Q1
市场空间

数字方向没变：第一季全业 GGR ₱87.60 亿（年减 15.87%）、线上 ₱39.90 亿（年减 22.43%），第二季续弱（Philstar / BusinessWorld 7/17），官方数字月底出。PAGCOR 全年估 ₱3,200-3,500 亿，比 2025 的 ₱3,961 亿少一截。

这周多了一个变量：PAGCOR 降费率（线上→25%、实体→30%）。这是给运营商的实质成本减免，理论上能改善单位经济。但它跟盘子缩、AML 合规成本上升同时发生——降的是抽成、加的是合规投入，净效果对中小运营商不见得是正的。具体见 §04 卡 2、卡 3。

出处：Philstar 7/17 · 降费率 · PNA
Q2
玩家现在在意什么

玩家端痛点跟前几周一致，AML 令只会让它更明显：

出金卡在 GCash 验证。没实名、验证不过，提现被限额或卡住。AML 令要全业强化 CDD / 尽职调查，短期内实名、身份核验、资金来源审查只会更严——出金摩擦短期加剧、不是缓解。

入金走旁门。去年 8 月 BSP 令 GCash / Maya 解绑博彩后，玩家绕道 Lazada 储值券、Viber、加密 app。步骤变多、更容易被仿冒诈骗截走。

社群主调是后悔、想戒、怕诈骗。Reddit r/CasualPH 近期「never again」「addiction」「拜托别试」；热搜「怎么提款」「是不是诈骗」「怎么戒」。

X 上被 affiliate 洗版。搜 BingoPlus + withdraw / scam，最新全是分销号促销图。「快速出金 / 正规」这位置已被分销方话术占住。

判断：AML 令把「合法可查」的价值又抬高一层。玩家最怕钱卡住、被骗；监管现在逼全业做实名与资金来源审查，谁能把这套流程讲成「我们查得清、所以你拿得到」，谁就把合规成本转成信任卖点。喊「出金快」已经没用（被 affiliate 喊烂、又跟 AML 方向相反），改喊「实名怎么过、资金来源怎么证、到帐多久」才接得住人。

出处：Reddit r/CasualPH + AML 令 IAG 7/21
Q3
没人做的缺口

三个老缺口跟上周一样、都还空着：换版素材没人做成玩家看得懂愿意转的；入金 / 替代金流没人出教学；促销条款没人算给玩家看实际能拿多少。

AML 令新开一个缺口——KYC / 实名流程没人做成玩家看得懂的引导（验证要传什么、多久过、卡住怎么办）。四个不用砸钱，是信任 / 说明缺口不是预算缺口。具体见 §06 机会。

出处：本周窗口 8 家无新档 + AML 令外溢玩家端
Q4
价档结构

DigiPlus 走活动档、其他家走返利档，格局没变。1.5% 返利是入场券不是卖点，CasinoPlus、OKBet、Bet88、PlayTime 四家数字一样、条款也一样。

这周是价档退潮：嘉年华 7/23 收、世界杯 7/19 完（OKBet FIFA 奖池、Bet88 世界杯奖池到底、续档没影）、CasinoPlus 1.5% 档 7/31 到期。BingoPlus 往另一头走——VIP Club 重新包装，把资源从大众奖池转向高消费客群。下周盯 CasinoPlus 续档、独立运营商补不补体育档。

出处：价档沿用实读 + 世界杯 7/19 收 + VIP Club 7/19
Q5
差异化结论

差异化还是 DigiPlus 一边倒：自制赛事 IP、落地场地（LaVie）、₱200 亿现金加回购弹药，VIP Club 又往高端加码，别人拿不出对等的。供应链那头 PhilWeb 独家代理 Pragmatic Play 还卡在监管核准，一旦过了，持照运营商上 PP 内容就得过它这关。

结论：这周没新炸点，是结构面在动。SONA 今天讲、AML 令收紧、降费率、解构自营四条监管线同时走；DigiPlus 一边回购一边往高端集中。方向还是一致的：龙头更集中、监管手段变多（收紧、降费、拆分同时来）、盘子还在缩。

提议：跟 BingoPlus 拼奖池是找死，现在它连 VIP 排场都拉高了，更别跟。要打就打它拼不动、监管又在逼的那块：把实名 / 出金 / 入金 / 资金来源讲清楚给玩家，把 AML 收紧转成「我们查得清所以你拿得到」的信任素材。SONA 结果出来前合规先蹲低，别赌政策转向。以上是建议、不是结论。

出处：本周窗口综合判断 · SONA 7/27 政策变量

监管一边调降费率、一边要解构自己：解构后 8 月送总统府
