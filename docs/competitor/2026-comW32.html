▲Executive Briefing · 主管简报

这一周看点

这周三件事： 总统年度国会演说（SONA）对线上博彩一句没提、政府还没说要不要管； PAGCOR 上半年财报出来，总营收 -26.6%、净利 -85%、eGames -41.9%； 整合度假村入局线上，压 DigiPlus 毛利。

1. 总统年度国会演说没提线上博彩，连两年如此。
SONA 是菲律宾总统每年对国会的施政报告，总统当众定调这一年的国家大事、也常借这场演说宣布重大政策。7/27 这场（Marcos 任内第五次）讲了防洪弊案、税改、电力改革，全程没提线上博彩一个字——去年那场也没提。会前一堆议员喊话要总统当场处理，全落空。政府对外只说「还在研究、要看对社会的影响、暂时不打算全面禁」，正在找各方坐下来谈怎么管。等于政府还没决定要不要管、怎么管，维持现状。详 §04 卡 1。(出处：Philstar 7/28 · iGamingToday)

2. PAGCOR 上半年官方财报出来：总营收年减 26.6%、净利年减 85%、eGames / eBingo / bingo 年减 41.9%。
等了一个月的官方数字 7/30 出了。上半年总营收 ₱433 亿（约 US$7.05 亿），去年同期是创纪录的 ₱591 亿；主营的博彩营运收入 ₱389 亿、年减 27.1%；净利年减 85%（上缴给国库的钱变多也吃掉一块）。跌最凶的是线上——eGames / eBingo / bingo 合计年减 41.9% 到 ₱186 亿，对应去年央行（BSP）要求 GCash 这类电子钱包把博彩储值连结下架、玩家充值管道被切断。白纸黑字证明这个市场缩水是长期结构问题、不是一次性波动。详 §04 卡 2。(出处：IAG 7/30 · GGRAsia)

3. 大型实体赌场集团进军线上，抢 DigiPlus 的地盘、压它的利润。
券商 Abacus 7/28-7/29 出报告：Bloomberry（Solaire 母公司）主推 Solaire Online、还重启 FunaloMAX；Okada Manila、Newport World Resorts、Hann、NUSTAR 则找 PhilWeb 代运营线上平台。这些是有实体赌场的大集团（业内叫整合度假村 IR）。短期先打到 DigiPlus 的利润、还没动到它龙头地位——市佔仍约 41%，但地盘被瓜分，只能继续砸广告、促销守住份额。详 §04 卡 3。(出处：IAG 7/29 · AGB 7/28)

政策总统没喊禁、也没说放行，等于维持现状。政府还在研究要不要管，短期不会突然全禁（刚公布上半年营收大跌、不会同个月自己断税收）；同一条线上，PAGCOR 又把 B2B 认证死线从 7/31 延到 9/30，监管短期一直在放宽、没硬起来。投放照常、合规照做，但也别把「没提」当放行。
市场市场缩水已是官方数字（-26.6% / eGames -41.9%），首年目标沿用 -15~25% 下修；依据从估算换成官方上半年财报，更站得住脚。
竞争大集团上线抢客是新变量——同一批玩家被更多平台瓜分。趁 DigiPlus 忙着守地盘，进场者与其正面抢，不如去做没人做的那块：把「合规、能查、拿得到钱」讲清楚给玩家。体育空窗还开着，低成本内容先占。

§02Strategic Read · 5Q

战略解读 · 五问（中性陈述）

Q1
市场空间

官方数字出来了，方向跟前几周判断一致：PAGCOR 上半年总营收 ₱433 亿（约 US$7.05 亿）、年减 26.6%；主营博彩营运收入 ₱389 亿、年减 27.1%；净利年减 85%。跌最重的是线上——eGames / eBingo / bingo 合计年减 41.9% 到 ₱186 亿，对应去年央行（BSP）要求电子钱包下架博彩储值连结、玩家充值管道被切断。实体持照赌场只跌 3.85%、自营赌场跌 8.67%，落差摆明问题在线上、不在实体。券商同期把全年博彩收入（GGR）再下修约 7%。

上周的降费率（线上→25%、实体→30%）还在，是实质成本减免；但摆在 -26.6% 的半年数旁边看，降的是抽成、加的是合规投入、盘子还在缩，净效果对中小运营商更不确定。

出处：IAG 7/30 · BusinessWorld 7/30
Q2
玩家现在在意什么

玩家端痛点跟前几周一致，反洗钱（AML）令 + 电子钱包断链让它更明显：

出金卡在 GCash 实名验证。没实名、验证不过，提现被限额或卡住。入金走旁门。去年 8 月 BSP 令 GCash / Maya 解绑博彩后，玩家绕道 Lazada 储值券、Viber、加密 app，步骤多易被仿冒诈骗截走。

社群主调是后悔、想戒、怕诈骗。Reddit r/CasualPH「never again」「addiction」；热搜「怎么提款」「是否诈骗」「怎么戒」。X 上「快速出金 / 正规」被分销号话术占住。

判断：官方半年数把「线上在缩、钱更难进出」摆到台面。玩家最怕钱卡住、被骗；监管逼全业做实名 + 资金来源审查，谁能把这套讲成「我们查得清、所以你拿得到」，谁就把合规成本转成信任卖点。喊「出金快」已经没用，改喊「实名怎么过、资金来源怎么证、到帐多久」才接得住人。

出处：Reddit r/CasualPH（近周实证）+ PAGCOR 半年数 IAG 7/30
Q3
没人做的缺口

四个老缺口跟上周一样、都还空着：换版素材没人做成玩家看得懂愿意转的；入金 / 替代金流没人出教学；促销条款没人算给玩家看实际能拿多少；KYC / 实名流程没人做成玩家看得懂的引导。都不用砸钱，是信任 / 说明缺口不是预算缺口。

大集团上线又开一个缺口——几家平台同时抢同一批玩家，谁先把「合规、能查、拿得到钱」讲明白，谁先在混战里立住信任。具体做法见 §06 机会。

出处：本周窗口 7 家无新档 + 大集团上线 + 反洗钱外溢玩家端
Q4
价档结构

DigiPlus 走活动档、其他家走返利档，格局没变。1.5% 返利是入场券不是卖点，OKBet、Bet88、PlayTime 数字一样、条款也一样；CasinoPlus 的 1.5% 7/31 到期、续档没公布，改用 Color Game 累积奖池破 ₱1 亿当行销点——从价档转向 IP / 奖池叙事。

这周价档退潮延续：世界杯 7/19 完（OKBet FIFA 奖池、Bet88 世界杯奖池到底、续档没影）、CasinoPlus 1.5% 7/31 到期。下周盯 CasinoPlus 续档、独立运营商补不补体育档、IR 自营平台上线会不会带新价档。

出处：价档沿用实读 + 世界杯 7/19 收 + CasinoPlus 里程碑 7/30
Q5
差异化结论

差异化这周多了一条：DigiPlus 一家独大的局面，开始被大集团上线松动。原本 DigiPlus 靠自制赛事 IP、实体场地、₱200 亿现金加回购弹药、VIP Club 往高端加码，别人拿不出对等的；现在 Bloomberry（Solaire Online）＋ Okada / Newport / Hann / NUSTAR（委 PhilWeb）这几家有实体赌场的大集团带着自己的品牌和线下客群进线上，Abacus 判它们会慢慢啃 DigiPlus 份额、逼它继续砸广告。供应链那头 PhilWeb 独家代理 Pragmatic Play 还卡在核准，一旦过、持照运营商想上 PP 内容又得过它这关。

结论：这周没有新促销的大动作，动的是市场底盘，而且比前几周更明确——官方半年财报证明市场在缩（-26.6%），大集团上线证明龙头地盘开始被分食，总统演说没提证明政策还没定案。三件事指向同一个方向：市场在重整、龙头独大的局面开始松动、政府要不要收紧还没拍板但行政手段没停。

提议：跟 BingoPlus 拼奖池、跟大集团拼线下客群都不对——它们各有你没有的弹药。要打就打大家都还没占的那块：把「怎么实名、钱怎么进出、多久到帐」讲清楚给玩家。趁 DigiPlus 忙着守地盘、几家大集团忙着上线抢客的空档，去做没人占的信任这块。政府还没表态，合规继续照做、别赌政策会转向。以上是建议、不是结论。

出处：本周窗口综合判断 · 大集团上线 + 官方半年数 + SONA 结果

总统年度国会演说（SONA）连续两年对线上博彩只字未提

SONA（State of the Nation Address）是菲律宾总统每年对国会的施政报告，总统当众定调这一年的国家大事、也常借这场演说宣布重大政策。7/27 这场是 Marcos（现任总统）任内第五次，主题讲防洪弊案、税改、电力改革，全程没提线上博彩一个字——去年那场也没提。会前一堆议员喊话要总统当场处理（有人要全国禁、有人推反线上博彩法案），全落空。政府对外的说法还是「在研究、要看对社会的影响、暂时不打算一刀切全面禁」，正在找各方坐下来谈怎么管。
判断：总统没喊禁、也没说放行，等于维持现状——政府还没决定要不要管、怎么管。但就在公布上半年营收大跌 26.6% 的同一周，政府更不可能自己一刀切断掉这笔税收，短期突然全禁的机率更低。收紧还是会走行政手段那条线慢慢来：洗钱查核、广告换版、月保底费调高、拆分自营赌场。对操盘手：投放照常、不用为「演说当天出事」提心吊胆；该做的合规（广告换版、支付透明度）继续做。

§06Implications · 威胁 / 机会

影响推演（威胁 / 机会）

进场参数参考（皆为内部估算）
  • 总统年度演说（SONA）：没提线上博彩，等于政府维持现状、还没决定要不要管。短期不会突然全禁（刚公布营收大跌、不会同个月断税收），投放照常；但别把「没提」当放行。
  • 市场缩水已有官方数字：上半年 -26.6% / eGames -41.9% / 净利 -85%。首年获客目标沿用先前的 -15~25% 下修、依据从我们的估算变成官方半年财报。这条是本报所有「下修」建议的唯一出处、各卡不重复。
  • 大集团上线：存量市场多几个大集团自营 / 委外平台分食，整体获客成本（CPA）可能被促销战推高；同时 DigiPlus 忙着守份额、留出让我们做差异化素材的空档。
  • 反洗钱（AML）合规：相关文案（客户身份查核、可疑交易通报的措辞）审查趋严是未来 6-12 个月的方向；支付 / KYC 文案预算加一笔法务复核。
  • 换版素材：求助专线通用层先做保守版、估 ~₱150K-₱400K / 一次性；7/15 期限过、规格没出，先合规再微调。
  • MGF 每月固定支出：现在月 GGR 到不了 ₱3,000 万、每月先亏 ₱900 万；10/1 起变每月 ₱1,050 万。财务模型按 10/1 之后算。
  • B2B 认证延到 9/30（PAGCOR 7/20 备忘录、董事会 7/16 批、原死线 7/31）：官方理由是业界办证程序普遍拖延（7/20 仅 66 家过关）、未合规者 10/1 起才停机。判断：这是 PAGCOR 又一次把死线往后推、不是动真格——跟 SONA 没点名一致，短期别把合规死线当硬约束、但方向没变、该办的照办。
威胁（5 条）Threats
  • 市场缩水已有官方数字。上半年 -26.6%、eGames -41.9%、净利 -85%，问题在线上充值管道被切断、非一次性。不动的代价（内部估算）：模型若挂「下半年会反弹」的假设、首年营收会高估；先按官方的上半年财报，把首年目标挂 -15~25% 的下修。
  • 大型实体赌场集团进军线上、分食存量 + 可能触发促销战。Bloomberry / Okada / Newport / Hann / NUSTAR 这几家有实体赌场的大集团，自营或委外的线上平台陆续上线。不动的代价（内部估算）：几家大集团同时抢客、把获客成本（CPA）推高 20-40%，只按现在行情估会低估。
  • 总统没表态，政策没定案。既没喊禁、也没说放行，政府还在研究；洗钱查核、广告换版、月保底费调高、拆分自营赌场这些行政收紧没停。不动的代价（内部估算）：把「没提」当成「放行」就放大投放，万一政府之后再收紧、素材得紧急下架，投放跟素材两头落空。
  • AML 令让出金摩擦短期加剧 + 换版规格没出。全业重做 CDD / 资金来源审查；过了 7/15 挂旧版即违规。不动的代价（内部估算）：只盯 CPA、不盯入金成功率与提现体验，有效获客成本被低估 30-50%；等规格才动比先做保守版贵 2-3 倍。
  • DigiPlus 被迫砸广告 / 促销守份额、声量战升温。龙头忙着防守大集团，广告 / 促销可能加码。不动的代价（内部估算）：正面跟它拼声量 / 拼奖池，进场者的声量会被压掉 30-50%。
机会（4 条）Opportunities
  • 大集团上线 = 混战空档，去做没人占的信任这块（内部估算 ~₱200K-₱500K / 4 周）。DigiPlus 防守、几家大集团抢上线，没人占住「合规、能查、拿得到钱」这块。提醒：支付 / KYC 文案先过法务、别踩洗钱查核（CDD / STR）措辞雷、不引导绕过合规通道。
  • AML 收紧 → 把合规讲成信任素材（内部估算 ~₱200K-₱500K / 4 周）。全业被逼做实名 + 资金来源审查，没人把「实名怎么过、资金来源怎么证、到帐多久」做成玩家看得懂的引导。提醒：不引导绕过合规通道、法务先看。
  • 体育档真空（7/20-8 月初）好切（内部估算 ~₱100K-₱300K / 一次性）。世界杯完、NBA 未开季，对手体育档同时到期。用教学内容占它、不用大奖池。提醒：不碰「保证 / 稳赚」、法务先看。
  • 促销条款 / 奖池口径算给玩家看（内部估算 ~₱100K-₱300K / 一次性）。CasinoPlus 破亿是累积奖池、百家乐大赛条款没人把「实际能拿多少 / 到帐流程」讲清楚。提醒：引用竞品数字标累积口径、只讲事实不讲对手坏话、法务先看。
